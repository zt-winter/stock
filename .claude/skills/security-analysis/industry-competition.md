# 行业竞争格局分析

根据指定股票所在行业，获取行业内主要公司的市值、营收、净利润数据，分析行业竞争格局与集中度。

**CLI 工具**: `scripts/industry_competition_analysis.py`
**前置条件**: 无需提前采集财报数据，脚本通过 akshare 实时 API 获取所需数据

## 分析流程（AI 执行步骤）

执行行业竞争分析时，**必须**按以下顺序执行：

### Step 0：Web Search 确认行业（必选，在运行脚本之前执行）

**目的**：确保行业分类准确，避免因东财行业分类不精确导致分析偏移。

1. **搜索公司主营业务**：
   - 搜索关键词：`"[股票名称] 主营业务 所属行业"` 或 `"[股票代码] 公司简介 行业分类"`
   - 从搜索结果中提取：公司名称、主营业务描述、申万/证监会行业分类
   - 记录搜索结果中提及的具体行业名称

2. **与东财 API 结果交叉验证**：
   - 运行脚本获取东财行业分类（见 Step 1）
   - 对比 Web Search 结果与东财 API 返回的行业
   - 如果两者一致：直接使用
   - 如果两者不一致：
     - 优先采用 Web Search 中提及频率更高的行业分类
     - 若东财分类明显不合理（如将“贵州茅台”分到“饮料制造”而非“白酒”），使用 `--industry` 参数覆盖
     - 向用户确认行业分类后再继续

3. **确定最终行业名称**：
   - 行业名称必须与东方财富行业板块名称匹配（脚本内部会进行模糊匹配）
   - 如果不确定东财板块名称，可先运行脚本看其匹配结果

### Step 1：运行脚本获取行业成份股并分析

```bash
# 方式一：让脚本自动识别行业（东财 API）
python scripts/industry_competition_analysis.py analyze --code 600519

# 方式二：使用 Web Search 确认的行业名称覆盖
python scripts/industry_competition_analysis.py analyze --industry 白酒
python scripts/industry_competition_analysis.py analyze --code 600519 --industry 白酒
```

### Step 2：解读脚本输出，生成报告

基于脚本输出的数据，按本报告末尾的报告模板生成分析报告，并加入 Web Search 补充的行业背景信息。

## 脚本内部逻辑

### Step 1：识别公司行业
通过东方财富接口获取股票的公司信息，提取"行业"字段（东方财富行业分类）。

### Step 2：获取行业成份股
从东方财富行业板块接口获取该行业的所有上市公司列表。

### Step 3：获取财务数据
- **市值**: 通过 `stock_zh_a_spot_em` 获取实时总市值
- **营收/净利润**: 通过 `stock_yjbb_em` 获取最近一期业绩报表数据（自动判断可用报告期）

### Step 4：竞争格局分析
对行业内前 N 名公司（默认10，按市值排序）进行多维度分析：

| 分析维度 | 指标 | 说明 |
|----------|------|------|
| 市场集中度 | CR3/CR5/CR10 | 前N名合计市值/营收/利润占行业比重 |
| HHI 指数 | 赫芬达尔-赫希曼指数 | <1500=竞争型，1500-2500=适度集中，>2500=高度集中 |
| 龙头优势倍数 | No1 vs No2/No3/其余 | 第1名是第2/3名或其余之和的多少倍 |
| 断层分析 | 相邻排名倍数 | 相邻排名之间市值差距倍数 |

### 竞争格局判断规则

#### 一超多强（竞争激烈程度：低，价格战风险：低）
- **判定条件**: 龙头市值/营收/净利润是其余前10名之和的 2 倍及以上
- **含义**: 龙头地位极为稳固，行业胜负已分，发生恶性价格竞争的概率很低
- **投资启示**: 龙头具有极强护城河，适合长期持有

#### 寡头垄断（竞争激烈程度：中低，价格战风险：低）
- **判定条件**: CR3 > 60% 且 HHI > 2500
- **含义**: 少数几家企业主导市场，竞争格局相对稳定
- **投资启示**: 头部企业均有一定护城河，关注彼此间竞争态势

#### 寡头竞争（竞争激烈程度：中，价格战风险：中）
- **判定条件**: CR3 > 45%（介于寡头和充分竞争之间）
- **含义**: 头部有一定优势，但彼此竞争依然存在
- **投资启示**: 关注头部企业的增速分化

#### 群雄逐鹿（竞争激烈程度：中高，价格战风险：中高）
- **判定条件**: CR5 < 45% 且 HHI 介于1500-2500
- **含义**: 市场相对分散，多家企业实力相近
- **投资启示**: 需关注行业整合趋势，选择具有整合能力的企业

#### 充分竞争（竞争激烈程度：高，价格战风险：高）
- **判定条件**: CR5 < 40% 且 HHI < 1500
- **含义**: 市场参与者众多且实力接近，竞争激烈
- **投资启示**: 避免投资行业内的二三线企业，关注具有差异化竞争优势的龙头

## 脚本 CLI 用法

### 分析指定股票所在行业

```bash
# 分析贵州茅台所在行业（白酒）的竞争格局
python scripts/industry_competition_analysis.py analyze --code 600519

# 分析中远海控所在行业（航运）的竞争格局
python scripts/industry_competition_analysis.py analyze --code 601919

# 分析前8名（默认10名）
python scripts/industry_competition_analysis.py analyze --code 600519 --top 8
```

### 直接指定行业名称

```bash
# 跳过行业识别，直接分析白酒行业
python scripts/industry_competition_analysis.py analyze --industry 白酒

# 分析新能源汽车行业
python scripts/industry_competition_analysis.py analyze --industry 新能源汽车
```

## AI 解读框架

基于脚本输出数据，从以下维度进行解读：

### 1. 行业竞争格局定性
- 龙头是否具有压倒性优势（一超多强 vs 寡头 vs 群雄逐鹿）
- 前三名之间是否存在明显断层
- 龙头市值/营收/利润是否为其余前10之和的2倍以上（胜负已分信号）

### 2. 竞争稳定性评估
- 前3名市场份额是否稳定
- 相邻排名差距是否足够大（>2倍说明护城河明显）
- HHI指数是否在合理集中区间（1500-2500为佳，既有规模效应又不过度垄断）

### 3. 恶性竞争风险
- 头部企业营收/利润增速是否分化（增速相近则竞争加剧）
- 是否有新进入者威胁（通过观察近1年排名变化）
- 行业是否处于产能过剩周期（结合周期股分析）

### 4. 目标股票定位
- 目标股票在行业中的排名和地位
- 与龙头的差距有多大
- 是否具有差异化竞争优势

## 注意事项

1. **行业分类**: 使用东方财富行业分类，可能与申万行业分类有差异
2. **数据时效**: 市值为实时数据，营收/利润为最近一期业绩报表（可能有4个月滞后）
3. **港股限制**: 目前仅支持A股，港股暂不支持
4. **网络依赖**: 需要调用东方财富API，请确保网络畅通
