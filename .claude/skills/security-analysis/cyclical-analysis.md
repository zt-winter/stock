# 周期股分析

判断公司主业是否为大宗商品/周期股，若是则获取近10年 PE/PB 与季度财务数据，按六维分析框架生成周期分析报告。

**CLI 工具**: `scripts/cyclical_stock_analysis.py`
**分析方法论**: [cyclical-analysis-guide.md](cyclical-analysis-guide.md)（PE/PB反转逻辑、库存周期四阶段、报告模板、常见陷阱）

## 判断规则

### 大宗商品/周期股行业特征

符合以下**任一**条件即判定为周期股：

1. **主业涉及大宗商品**: 钢铁、有色金属（铜/铝/锌/镍/锂/稀土等）、煤炭、石油天然气、黄金贵金属、化工（基础化工/化肥/纯碱/MDI/钛白粉等）、水泥建材、造纸、橡胶
2. **产品价格高度波动**: 公司主要产品为标准化商品，价格受供需周期、产能周期、库存周期影响大
3. **强周期行业**: 航运、房地产、工程机械、汽车整车、半导体（存储芯片）
4. **农业周期**: 生猪养殖（猪周期）、种业、大宗农产品

### 非周期股特征

消费品（食品饮料/家电/服装）、医药、公用事业、银行保险、软件/互联网、传媒 —— 通常**不是**周期股。

### 判断步骤

1. 根据股票代码识别公司名称和行业
2. 分析公司主营产品是否属于上述大宗商品/周期品类别
3. 向用户确认判断结论后，再执行后续数据采集

## 数据采集与分析

确认是周期股后，执行以下步骤：

### Step 1: 采集财报数据（如尚未采集）

检查 `financial_data.db` 中是否已有该股票的财报数据：

```bash
python -c "import sqlite3; conn=sqlite3.connect('financial_data.db'); cur=conn.cursor(); cur.execute(\"SELECT COUNT(*) FROM em_income_statement WHERE stock_code='XXXXXX'\"); print(cur.fetchone()[0])"
```

如果数据为空，用 `scripts/collect_financial_data.py` 采集：

```bash
python scripts/collect_financial_data.py collect --code XXXXXX --market sh --start-year 2016
```

### Step 2: 运行周期股分析脚本

```bash
# 估值 + 财务 + 库存周期分析（推荐）
python scripts/cyclical_stock_analysis.py inventory --code 600519 --market sh

# 完整分析（估值 + 季度财务数据）
python scripts/cyclical_stock_analysis.py full --code 600519 --market sh

# 仅估值数据（PE/PB）
python scripts/cyclical_stock_analysis.py valuation --code 600519
```

输出内容:
- 近10年 PE(TTM) 和市净率(PB) 季度末值
- 每季度归母净利润（TTM）和经营现金流（TTM）
- PE/PB 的历史最低值、中位数、最高值、当前值
- **PE/PB 反转分析**: 找 PE 最高/最低时对应的利润水平，验证周期股反转现象
- **库存周期四阶段**: 每季度存货、毛利率、预收/合同负债、应付账款，识别所处阶段
- **阶段转换时间线**: 汇总各阶段切换的时间节点

### Step 3: AI 解读与报告生成

**重要**: 在分析前，必须完成以下阅读：
1. 先阅读 [cyclical-analysis-guide.md](cyclical-analysis-guide.md) 了解周期股分析方法论
2. 查阅 [knowledge/INDEX.md](knowledge/INDEX.md)，若当前行业有对应知识文件，必须一并阅读

行业知识会影响解读角度：调整指标阈值（如白酒毛利率75-82% vs 铝业10-20%）、识别行业特有陷阱、选择正确的领先指标。

基于脚本输出数据，结合行业知识，按六维分析框架进行解读：

1. **估值周期**: PE/PB 当前处于历史什么分位（注意：周期股低 PE ≠ 低估，可能代表利润过热）
2. **利润周期**: 净利润 TTM 的变化趋势，识别峰值/谷值，计算周期波幅倍数
3. **现金流验证**: 经营现金流与净利润的比值（行业知识文件中有各行业的正常范围）
4. **PE/PB 反转分析**: PE 最高时对应利润谷值（周期底部），PE 最低时对应利润峰值（周期顶部）
5. **库存周期四阶段**: 基于存货环比 + 毛利率趋势识别阶段，梳理历史周期轮次
6. **综合周期位置判断**: 汇总 5 个维度信号，给出当前处于底部/上升/顶部/下降的判断

### 报告格式强制要求

**七段式结构缺一不可**，每段必须包含以下内容：

#### 【一、周期股确认】
- 公司主业描述
- 匹配的周期股判定规则
- 利润波动系数(CV)量化验证（CV>0.5为强周期，>1.0为极强周期）
- 峰/谷均值比（>2倍表明周期波动显著）

#### 【二、估值统计】
- PE/PB 四值表格：最低、中位数、最高、当前
- 当前 PE/PB 分位数及含义（<25%=利润高位区，>75%=利润低位区）
- 注意周期股低PE的反转含义

#### 【三、PE/PB 反转分析】（核心章节，不可省略）
- PE 最高/最低对照表：日期、PE、PB、归母净利润TTM
- **利润倍数计算**：PE最低时利润 / PE最高时利润（>5倍=典型强周期）
- **PB 反转**：对比 PE 最高/最低时的 PB 值
- **当前定位**：当前 PE 更接近最高值还是最低值，说明利润处于什么位置
- **反转强度评级**：极强(>20倍) / 强(5-20倍) / 中等(2-5倍) / 弱(<2倍)

#### 【四、利润周期】
- 利润周期时间线表格：阶段、时期、利润TTM、特征
- 利润波幅倍数（峰值/谷值）
- 当前利润历史分位（0%=历史最低，100%=历史最高）
- 近4季度趋势判断（上升/下滑/企稳）
- 利润拐点识别（连续2季环比同向变化=拐点确认）

#### 【五、现金流验证】
- 现金流/利润比表格：时期、净利润TTM、经营现金流TTM、比值、质量评级
- 平均现金流/利润比
- 覆盖利润的季度数占比
- 利润质量总评（高/正常/存疑/差）

#### 【六、库存周期分析】（核心章节，不可省略）
- **按轮次梳理**：将历史数据划分为多个库存周期轮次（第1轮、第2轮...），每轮包含起始时间、阶段演变、库存变化、毛利率变化、解读
- **毛利率趋势**：每轮周期中毛利率的高点和低点，毛利率环比变化方向
- **阶段判断**：基于库存环比 + 毛利率趋势 + 预收/合同负债 + 应付账款四指标综合判断
- **当前阶段**：明确指出当前处于哪个阶段（1-上升/2-扩张/3-收缩/4-衰退），并说明判断依据
- **行业特殊性说明**：不同行业的"库存"含义不同（航运=运力，养殖=存栏，化工=产成品库存）

#### 【七、综合周期位置判断】
- **5信号汇总表**：PE分位、PB分位、利润趋势、库存周期阶段、现金流/利润比，每个信号对应周期底部/上升/顶部/下降的哪个位置
- **综合研判**：当前处于周期的 [底部/上升/顶部/下降] 区域
- **判断可信度**：≥3个信号指向同一位置=可信度高，信号分歧=以库存周期和毛利率为主
- **投资提示**：周期股布局时机、风险提示、需跟踪的领先指标

### 数据缺失处理规则

当某项数据缺失或无法获取时，**章节结构必须保留**，内容填写缺失说明：

| 缺失情况 | 处理方式 |
|----------|----------|
| 某季度财务数据缺失 | 表格中该行标注「数据缺失」，不影响其他行 |
| 经营现金流数据不可用 | 【五、现金流验证】章节保留，表格标注「N/A」，总评写「数据不足，无法验证」|
| 存货/毛利率数据缺失 | 【六、库存周期】章节保留，标注「数据不足，无法划分轮次」，仅列出已有数据 |
| 利润CV无法计算 | 【一、周期股确认】标注「利润数据不足，无法计算CV」，保留定性判断 |
| PE/PB 历史数据不足 | 【三、反转分析】标注「历史数据不足X年，反转分析参考价值有限」|

**原则：宁可章节内容为空，不可删减章节。** 完整的七段式结构是报告的骨架，缺失章节会破坏分析框架的完整性。

报告完整模板见 [cyclical-analysis-guide.md](cyclical-analysis-guide.md) 中的"报告输出模板"章节。

## 行业对比分析

当需要分析**整个行业**的周期位置时（如白酒、钢铁、有色金属等），必须对行业内多只代表性股票分别执行完整的七段式分析，然后汇总对比。

### 执行流程

1. **确定行业代表股票**（通常 5-8 只，涵盖龙头和二线）
2. **逐只运行 `inventory` 命令**：
   ```bash
   python scripts/cyclical_stock_analysis.py inventory --code XXXXXX --market sh/sz
   ```
   注：估值数据会自动缓存到数据库（7天有效期），重复运行时加 `--refresh` 强制刷新
3. **汇总七段式对比表**：

### 行业对比报告模板

```markdown
## [行业名称] 行业周期分析报告

### 一、行业周期股确认
- 行业特征描述
- 判定依据
- 代表股票列表

### 二、估值统计对比
| 公司 | PE最低 | PE中位数 | PE最高 | PE当前 | PE分位 | PB当前 |
|------|--------|----------|--------|--------|--------|--------|
| ... | ... | ... | ... | ... | ... | ... |

### 三、PE/PB 反转分析对比
| 公司 | PE最高时利润 | PE最低时利润 | 利润倍数 | 反转强度 |
|------|--------------|--------------|----------|----------|
| ... | ... | ... | ... | ... |

### 四、利润周期对比
| 公司 | 利润峰值 | 利润谷值 | 波幅倍数 | 当前vs峰值 |
|------|----------|----------|----------|------------|
| ... | ... | ... | ... | ... |

### 五、现金流质量对比
| 公司 | 近期现金流/利润比 | 质量评价 |
|------|-------------------|----------|
| ... | ... | ... |

### 六、库存周期对比
| 公司 | 当前阶段 | 近4Q存货变化 | 毛利率趋势 | 去库进度 |
|------|----------|--------------|------------|----------|
| ... | ... | ... | ... | ... |

### 七、行业综合判断
1. **行业整体周期位置**：汇总各公司信号分布
2. **内部分化程度**：龙头vs二线是否同步
3. **去库存进度评估**：是否已全面去库存
4. **投资提示**：行业整体处于什么阶段，适合什么策略
```

### 关键原则

- **七段式缺一不可**：即使只关注库存周期，也必须提供估值、利润、现金流等完整背景
- **数据先行**：确保所有代表股票都有估值数据（PE/PB），否则无法进行反转分析
- **缓存利用**：估值数据会自动缓存到数据库，批量分析时第二次运行会更快
