# 周期股分析方法论

本文档是 AI 执行周期股分析时的**解读框架和判断准则**。脚本负责采集数据，AI 负责按此方法论解读数据并生成报告。

## 一、核心认知：周期股 vs 常规股的估值逻辑

### PE/PB 反转现象

周期股的 PE/PB 信号与常规股**完全相反**：

| | 常规成长股 | 周期股 |
|---|---|---|
| **PE 很高** | 市场预期高增长，可能是买入信号 | 利润被周期底部压缩到极低，是**危险信号**（周期底部） |
| **PE 很低** | 增长乏力，可能是卖出信号 | 利润处于周期高峰爆发期，是**危险信号**（周期顶部） |
| **PB 很低** | 可能被低估 | 资产质量可能恶化，需结合库存周期判断 |

**关键公式**：PE = 市值 / 净利润。周期股利润波动极大（可达 10-50 倍），而市值波动远小于利润波动，所以 PE 主要由利润驱动。

### 周期位置与 PE 的关系

```
周期底部 → 产品价格新低 → 利润极低 → PE 极高（可能几百倍甚至亏损）
周期上升 → 产品涨价 → 利润快速恢复 → PE 快速下降
周期顶部 → 产品价格新高 → 利润爆发 → PE 极低（可能不到10倍）
周期下降 → 产品跌价 → 利润快速萎缩 → PE 快速上升
```

**投资格言**："周期股在高 PE 时买入，在低 PE 时卖出"——与常规股相反。

## 二、六维分析框架

### 维度1：估值周期分析

**数据源**: 脚本输出的 PE/PB 统计数据（最低、中位数、最高、当前值）

**分析方法**:
1. 计算当前 PE 在历史中的分位：
   - PE < 历史 25% 分位 → 利润高位区域（周期顶部信号）
   - PE 在 25%-75% → 中间区域
   - PE > 历史 75% 分位 → 利润低位区域（周期底部信号）
2. 对比 PB 分位作为交叉验证
3. **注意**：对周期股，低 PE 分位不代表"低估"，可能代表"利润过热"

### 维度2：利润周期分析

**数据源**: 脚本输出的归母净利润 TTM 季度序列

**分析方法**:
1. **识别利润峰值和谷值**：找到近 10 年 TTM 利润的最高点和最低点
2. **计算利润波幅**：峰值 / 谷值 = 周期波幅倍数（周期股通常 > 5 倍，极端可达 20-50 倍）
3. **识别利润拐点**：
   - 连续 2 个季度 TTM 利润环比下降 → 下行拐点确认
   - 连续 2 个季度 TTM 利润环比上升 → 上行拐点确认
4. **同比增速分析**：
   - TTM 利润同比增速从正转负 → 利润见顶信号
   - TTM 利润同比增速从负转正 → 利润见底信号
5. **绘制利润周期时间线**：标注每一轮的峰/谷时间

### 维度3：现金流质量验证

**数据源**: 脚本输出的经营现金流 TTM 和净利润 TTM

**分析方法**:
1. 计算 **现金流/利润比** = 经营现金流 TTM / 归母净利润 TTM
2. 判断标准：
   - 比值 > 1.5 → 利润质量非常好（大宗商品的特征，现金回款强）
   - 比值 1.0-1.5 → 利润质量正常
   - 比值 < 1.0 → 利润质量存疑（可能有应收账款积压）
   - 比值 < 0.5 → 利润质量差（需警惕）
3. **周期性特征**：周期股在利润高峰期，现金流/利润比通常会升高（因为折旧摊销等固定成本占比下降），这是正常现象

### 维度4：PE/PB 反转分析

**数据源**: 脚本输出的 PE 最高/最低点对应的利润水平

**分析方法**:
1. **找 PE 最高时**：记录日期、PE、PB、TTM 利润
   - 这通常是**周期底部**——产品价格低迷、利润被压缩到极低
   - PE 可能高达几百倍（接近亏损）
2. **找 PE 最低时**：记录日期、PE、PB、TTM 利润
   - 这通常是**周期顶部**——产品价格高企、利润爆发
   - PE 可能低到个位数
3. **计算利润倍数**：PE 最低时的利润 / PE 最高时的利润
   - 倍数 > 5 → 典型强周期股
   - 倍数 2-5 → 中等周期股
   - 倍数 < 2 → 周期特征不明显
4. **当前定位**：当前 PE 更接近 PE 最高值还是最低值？
   - 接近最低值 → 利润高峰期，可能在周期顶部区域
   - 接近最高值 → 利润低谷期，可能在周期底部区域

### 维度5：库存周期分析

**数据源**: 脚本输出的季度存货、毛利率、预收/合同负债、应付账款数据

#### 库存周期四阶段

```
    阶段1-上升期          阶段2-扩张期
    (去库提价)            (补库高位)
    库存↓ 毛利率↑        库存↑ 毛利率稳/↑
         ↓                    ↓
    阶段4-衰退期          阶段3-收缩期
    (减产去库)            (累库跌价)
    库存↓ 毛利率↓        库存↑ 毛利率↓
```

| 阶段 | 供需关系 | 库存 | 毛利率 | 预收/合同负债 | 应付账款 | 含义 |
|------|----------|------|--------|--------------|----------|------|
| 1-上升 | 供不应求 | ↓ | ↑ | ↑（下游抢货） | ↓（采购少） | 最佳投资阶段，产品涨价 |
| 2-扩张 | 扩产补库 | ↑ | 稳/↑ | 稳/↑ | ↑（采购多） | 景气延续，但需关注供给 |
| 3-收缩 | 供过于求 | ↑ | ↓ | ↓（需求萎缩） | ↑（惯性采购） | 危险信号，价格拐点 |
| 4-衰退 | 减产出清 | ↓ | ↓ | ↓（需求冰冻） | ↓（削减采购） | 最差阶段，等待底部 |

#### 财报指标与阶段对应关系

- **存货（INVENTORY）**: 资产负债表时点数，直接看环比变化
  - 环比上升 → 累库
  - 环比下降 → 去库
- **毛利率**: (单季营业收入 - 单季营业成本) / 单季营业收入
  - 用 4 季度滚动平均平滑季节波动，再看环比变化
  - 毛利率上升 → 产品涨价或成本下降（利好）
  - 毛利率下降 → 产品跌价或成本上升（利空）
- **预收款/合同负债（ADVANCE_RECEIVABLES + CONTRACT_LIAB）**:
  - 反映下游客户提前付款/订货的意愿
  - 上升 → 下游需求旺盛，愿意提前打款锁定货源
  - 下降 → 下游需求萎缩，不愿提前付款
  - 注: 2020年会计准则变更，预收款重分类为合同负债，需合并看待
- **应付账款（ACCOUNTS_PAYABLE）**:
  - 反映向上游采购的赊购规模
  - 扩张期采购增多 → 应付账款上升
  - 收缩期如果应付账款仍上升 → 可能是惯性采购，库存积压风险

#### 阶段判断要点

1. **四阶段不一定完整出现**：实际数据中，可能跳过某个阶段（如从阶段1直接到阶段3），或某个阶段只持续 1-2 个季度
2. **季度噪音**：单季度数据可能有波动，需结合 2-3 个季度趋势综合判断
3. **行业特殊性**：
   - 铝/钢铁等重资产行业：库存变化幅度大，阶段持续时间长（2-4 个季度）
   - 化工/农产品：库存周转快，阶段切换频繁（1-2 个季度）
   - 养殖（猪周期）：库存周期受生物周期约束，阶段持续时间较长

### 维度6：综合周期位置判断

将前 5 个维度的信号汇总，给出当前位置判断：

| 信号 | 周期底部 | 周期上升 | 周期顶部 | 周期下降 |
|------|----------|----------|----------|----------|
| PE 分位 | >75%（高PE） | 从高往低走 | <25%（低PE） | 从低往高走 |
| 利润趋势 | 接近谷值 | 环比持续上升 | 接近峰值 | 环比开始下降 |
| 现金流/利润 | <1（最差时期） | 逐步改善 | >1.5（最好时期） | 开始恶化 |
| 库存阶段 | 阶段4-衰退 | 阶段1-上升 | 阶段2-扩张（后期） | 阶段3-收缩 |
| 毛利率 | 历史低位 | 触底回升 | 历史高位 | 见顶回落 |

**综合判断逻辑**:
1. 5 个信号中 ≥3 个指向同一位置 → 该位置判断可信度高
2. 信号分歧时 → 以库存周期阶段和毛利率趋势为主（最直接反映供需）
3. 注意时间错位 → PE/利润是滞后指标，库存/毛利率是领先指标

## 四、常见陷阱

1. **"低 PE 陷阱"**：周期股 PE 很低时，利润处于高峰，一旦产品价格下跌，利润会快速缩水，PE 会迅速飙升
2. **"高毛利率陷阱"**：毛利率处于历史高位时，可能意味着产品价格已经充分反映利好，上行空间有限
3. **"库存滞后"**：库存是滞后指标，当财报显示库存大幅上升时，价格可能已经开始下跌
4. **"季度噪音"**：单季度数据波动大，不要过度解读单个数据点，要看 2-3 个季度的趋势
5. **"行业差异"**：不同行业的库存周期长度和幅度差异很大，不要机械套用阈值
