# 有色金属 — 铝业

## 行业基本面

- **周期强度**: 强周期大宗商品
- **核心驱动**: 供需周期 + 宏观经济周期，产品价格高度波动
- **商业模式**: 重资产、高经营杠杆、产品同质化（电解铝是标准化商品）、成本敏感型
- **经营杠杆**: 固定成本（电力、设备折旧）占比高，产品价格小幅变动可导致利润巨幅波动

## 周期驱动因素

1. **产能周期**（主驱动，3-5年）: 电解铝产能建设周期约2-3年，达产需1年。产能集中投放 → 供过于求 → 价格下跌 → 部分产能退出 → 供不应求 → 价格上涨 → 新一轮扩产
2. **库存周期**（1-2年）: 社会库存（LME/SHFE仓库）+ 企业库存，库存快速积累或消耗放大价格波动
3. **宏观经济周期**: 铝是工业基础材料，需求与GDP、房地产、基建、汽车高度相关
4. **政策周期**: 环保限产、能耗双控、产能天花板（中国电解铝产能上限约4500万吨）

典型周期长度: 3-5年，比白酒短但波动幅度远大于白酒

## 关键指标调整

### 毛利率

- **正常区间**: 10-20%（远低于白酒的75-82%）
- **波动幅度**: 5-15个百分点（周期顶部可达25-30%，底部可降至5%以下甚至为负）
- **毛利率变化直接反映铝价**: 电解铝成本相对刚性（电力+氧化铝占70%+），毛利率变动主要由产品售价驱动
- **通用方法论中的 `gm_threshold = 0.003`** 对铝业偏小，建议调大到 `0.005-0.01`

### 存货

- **存货构成**: 原材料（铝土矿/氧化铝）+ 在产品 + 产成品（电解铝/铝材）
- **存货周转**: 比白酒快得多（30-90天），存货变化更灵敏
- **存货上升含义**: 几乎总是负面信号（产品滞销或价格下跌导致主动去库意愿不足）
- **存货下降含义**: 通常是正面信号（需求旺盛、去库顺利）
- **注意**: 铝企存货绝对金额大（几十亿到上百亿），需看环比百分比变化

### 应付账款

- **核心信号**: 铝业上游是氧化铝/电力供应商，应付账款大幅增加 → 原材料赊购增加 → 可能在扩产
- **应付账款下降**: 可能缩减采购或议价能力下降
- **与存货交叉分析**: 存货上升 + 应付账款上升 = 扩产补库（阶段2）；存货上升 + 应付账款下降 = 被动累库且现金流紧张（阶段3）

### 现金流/利润比

- **正常范围**: > 2.0x（重资产行业，折旧摊销大，现金流远超利润）
- **中国铝业实测**: 常年维持在 2.5x 以上
- **低于 1.5x**: 需警惕，可能利润中含大量应收账款（赊销）
- **与白酒对比**: 白酒 0.8-1.2x 即正常，铝业需 > 2.0x 才算健康

### 营业收入/营业成本

- **成本结构刚性**: 电力（35-40%）+ 氧化铝（30-35%）+ 其他（碳素、人工等），成本弹性低
- **利润弹性**: 铝价每上涨10%，利润可能上涨50-100%（经营杠杆效应）
- **关注**: 氧化铝价格变动（上游成本）和铝价变动（产品售价）的剪刀差

## PE反转特征

- **典型利润倍数**: 10-20x+，周期底部可能**亏损**（PE为负值，无意义）
- **中国铝业实测**: PE 从 326x（2019年利润8.5亿）降至 8.9x（2025年利润124.5亿），利润倍数 14.6x
- **PE区间**: 底部 8-15x（利润高峰），顶部 100-300x 或亏损（利润低谷）
- **PB区间**: 底部 0.8-1.5x，顶部 3-5x
- **PB比PE更可靠**: 因为亏损期PE无意义，PB始终有效。PB < 1.0 通常是周期底部区域

## 库存周期特点

- **四阶段持续时间**: 每个阶段 2-4 个季度（比消费品长）
- **阶段切换速度慢**: 重资产行业产能调整慢，阶段切换不如消费品清晰
- **行业特殊性**:
  - 阶段1（上升/去库提价）: 铝价快速上涨，社会库存快速消耗，下游恐慌性补货
  - 阶段2（扩张/补库）: 新产能陆续投产，库存开始回升但价格仍高位运行
  - 阶段3（收缩/累库跌价）: 产能过剩显现，铝价开始下跌但产量惯性大（停炉成本高），库存快速积累
  - 阶段4（衰退/减产去库）: 高成本产能关停（电解铝停炉重启成本极高），供给收缩后库存开始下降
- **关键差异**: 电解铝停炉后重启需3-6个月且成本极高，因此产能退出是真实的，不会像化工行业那样快速复产

## 行业分化规律

- **龙头企业（中国铝业/中国宏桥）**: 规模大、成本低（自备电厂），周期波动相对温和但仍很大
- **高成本企业**: 电力成本高的企业（如使用网电的企业）在周期底部率先亏损
- **铝加工 vs 电解铝**: 铝加工企业（如下游铝型材）周期波动小于上游电解铝企业
- **步调基本同步**: 铝是标准化商品，全行业价格一致，周期步调高度同步（不像白酒分高端/次高端）

## 常见陷阱

1. **亏损期PE陷阱**: 周期底部铝企经常亏损，PE为负值完全无意义。此时必须改用PB判断底部位置
2. **成本刚性陷阱**: 毛利率看似只下降5个百分点（从15%→10%），但利润可能已下降50%（因为经营杠杆）
3. **产能周期滞后**: 财报显示扩产时，新产能可能2-3年后才真正投产，当前库存变化可能不代表未来供需
4. **社会库存 vs 企业库存**: 财报只反映企业库存，LME/SHFE社会库存变化需要另外跟踪
5. **铝价与利润的非线性关系**: 铝价上涨10%可能带来50%利润增长（经营杠杆），反之亦然。不要线性外推
6. **政策风险**: 能耗双控/碳交易可能突然改变行业成本曲线，无法从财报预测
