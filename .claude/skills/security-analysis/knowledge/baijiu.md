# 白酒行业

## 行业基本面

- **周期强度**: 弱周期消费品（非强周期大宗商品）
- **核心驱动**: 消费需求周期（经济景气度 + 政商宴请需求），而非产能或库存周期
- **商业模式**: 品牌壁垒极高、先款后货（经销商预付货款）、毛利率远超一般行业
- **与大宗商品周期股的区别**: 白酒价格波动温和，品牌定价权强，利润波动主要受需求端而非供给端驱动

## 周期驱动因素

1. **消费需求周期**（主驱动）: 经济上行 → 商务活动增多 → 高端白酒需求上升 → 提价放量 → 利润增长
2. **库存周期**（次要）: 经销商库存 + 酒厂基酒库存，但基酒需陈放3-5年，库存调整慢
3. **政策周期**: 反腐/限酒令等政策冲击（如2012-2013年八项规定导致高端白酒需求骤降）
4. **产能周期**: 基酒产能扩张需3-5年建设+陈放，存在供给滞后效应

典型周期长度: 5-8年（消费周期），远长于大宗商品的3-5年

## 关键指标调整

### 毛利率

- **正常区间**: 75-82%（远高于大宗商品的10-20%）
- **波动幅度**: 2-3个百分点的变动已算显著（大宗商品需5-10个百分点才算显著）
- **毛利率下降的含义**: 产品结构下移（高端→中低端占比增加）或渠道让利加大，不一定是产品价格下跌
- **通用方法论中的 `gm_threshold = 0.003`**（0.3个百分点）对白酒适用

### 存货

- **行业特殊性**: 白酒存货包含大量**基酒**（需陈放3-5年才能勾兑出厂），基酒储备是生产必需而非滞销
- **存货上升 ≠ 负面**: 可能是主动增加基酒储备（为未来高端产品备货），尤其是茅台、五粮液
- **判断标准**: 需结合合同负债和营收增速判断——存货上升 + 合同负债上升 + 营收增长 = 主动备货（利好）；存货上升 + 合同负债下降 + 营收放缓 = 被动累库（利空）
- 存货周转天数 200-400 天为正常（远高于一般制造业的30-60天）

### 合同负债（预收款）

- **核心领先指标**: 经销商提前打款订货的意愿直接反映终端需求
- **季节性极强**: Q1（春节前）和 Q4（年底打款）通常是高点，Q2/Q3 相对低点
- **2020年会计准则变更**: 之前用"预收账款"(ADVANCE_RECEIVABLES)，之后用"合同负债"(CONTRACT_LIAB)，需合并看待
- **趋势判断**: 合同负债同比增长 > 10% → 需求旺盛；同比下降 → 渠道信心不足
- **单季度波动大**: 看 4 季度滚动合计或同比更有意义

### 现金流/利润比

- **正常范围**: 0.8-1.2x（先款后货模式保证现金流质量）
- **高端白酒**: 通常 > 1.0x（茅台常年接近 1.0x）
- **低于 0.7x**: 需警惕，可能渠道压货严重或回款困难
- **注意**: 白酒企业现金流质量普遍优于大宗商品企业

## PE反转特征

- **典型利润倍数**: 9-27x（PE最高时利润 / PE最低时利润）
- **行业内差异**:
  - 最极端: 山西汾酒（27x），清香型白酒周期波动最大
  - 最温和: 五粮液/今世缘（9x），高端白酒品牌护城河缓冲周期
  - 中等: 茅台（14.7x）、古井贡酒（14.2x）、泸州老窖（17.9x）、洋河（10.3x）
- **PE区间**: 底部 10-15x，顶部 55-143x（山西汾酒极端），中位数 23-37x
- **PB区间**: 底部 1.2-2.9x，顶部 10-42x

## 库存周期特点

- **四阶段持续时间**: 每个阶段 2-4 个季度（比大宗商品稍短）
- **阶段切换**: 可能不如大宗商品清晰，因为基酒库存受生产周期约束
- **行业特殊性**:
  - 阶段1（上升/去库提价）: 持续时间较长，因为基酒供给弹性低
  - 阶段2（扩张/补库）: 高端白酒主动增加基酒储备，存货持续上升但毛利率不降
  - 阶段3（收缩/累库跌价）: 主要在次高端和区域酒企先出现
  - 阶段4（衰退/减产去库）: 龙头企业很少进入此阶段，二三线酒企先衰退

## 行业分化规律

- **高端（茅五泸）**: 品牌力强，周期波动最温和，利润底部有品牌溢价支撑。茅台/五粮液即使在行业低谷也能维持较高毛利率
- **次高端（洋河/汾酒/酒鬼酒）**: 周期波动最大，行业下行时利润暴跌甚至亏损（如洋河从105亿→10亿，酒鬼酒亏损）
- **区域龙头（今世缘/古井贡酒）**: 受区域经济影响大，分化明显
- **步调不同步**: 高端见顶可能晚于次高端，复苏也可能早于次高端。分析时需分板块判断

## 常见陷阱

1. **基酒存货陷阱**: 白酒存货上升不等于滞销，大量基酒是生产必需。需结合合同负债和营收增速综合判断
2. **季节性干扰**: 白酒收入/预收款有极强的春节/Q4季节性，必须用 TTM 或同比消除季节影响
3. **高端vs次高端分化**: 不能用茅台的情况推断整个行业，次高端可能已经进入衰退而高端仍在扩张
4. **"低PE=利润高峰"适用但有例外**: 洋河当前PE 60x但利润暴跌，这是因为利润下降速度远快于股价下跌速度
5. **政策冲击非线性**: 白酒受政策影响极大（反腐/消费税/限酒令），政策风险无法从财报数据预测
6. **亏损期PE无意义**: 酒鬼酒等亏损企业PE为负，此时应看PB和PS（市销率）判断底部
