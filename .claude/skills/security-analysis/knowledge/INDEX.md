# 行业知识库

行业特定的分析知识，与周期股方法论 [cyclical-analysis-guide.md](../cyclical-analysis-guide.md) 分层协作。

## 使用方式

1. 分析某行业前，先查下方**路由表**找到对应知识文件
2. 读取行业知识文件，了解该行业的分析要点、阈值调整和常见陷阱
3. 再读取 [cyclical-analysis-guide.md](../cyclical-analysis-guide.md) 了解周期股六维分析框架
4. 运行脚本获取数据，**结合行业知识解读**数据并生成报告

若路由表中无对应行业，则仅使用通用方法论进行分析。

## 新增行业知识规范

每个行业知识文件应包含以下章节（可按需增减）：

```markdown
# [行业名称]

## 行业基本面
- 周期强度（强/中/弱）
- 核心驱动因素
- 商业模式特点

## 周期驱动因素
- 主要周期类型（产能/库存/需求/政策）
- 周期长度和幅度特征

## 关键指标调整
- 毛利率正常区间及波动幅度
- 存货的行业特殊性（如白酒的基酒）
- 核心领先指标（如合同负债、产能利用率）
- 现金流/利润比的正常范围

## PE反转特征
- 典型利润倍数范围
- 行业内反转强度差异

## 库存周期特点
- 四阶段持续时间特征
- 阶段切换速度
- 行业特殊表现

## 行业分化规律
- 细分板块差异（高端vs中端vs低端）
- 龙头vs二线企业的周期步调

## 代表股票
- 分析该行业时应覆盖的股票清单

## 常见陷阱
- 该行业特有的分析误区
```
