# 财务报告下载器

## 概述

本技能提供从网络搜索、下载、验证并规范化存储上市公司财务报告PDF文件的完整工作流程。支持A股（沪深交易所）和港股（香港交易所）上市公司的年度报告和中期报告下载。

## 核心功能

### 1. 网络搜索与来源定位
- 搜索权威财报来源：公司官网投资者关系页面、香港交易所披露易、雪球、腾讯财经等
- 优先获取官方原始PDF文件，避免中间处理版本
- 支持中英文关键词搜索

### 2. PDF下载与验证
- 下载PDF文件到临时位置
- 使用pdfplumber提取第一页文本进行验证
- 验证标准：第一页包含公司名称和报告类型关键词
- 排除补充报告、业绩公告、错误文件

### 3. 规范化存储
- 按"公司名称_股票代码"格式创建子目录
- 按"公司名称_年份_年报/中报.pdf"格式命名文件
- 生成详细的下载清单和校验日志

### 4. 错误处理与重试
- 下载失败自动重试机制
- 验证失败文件隔离处理
- 提供详细的错误日志

## 工作流程

### 第1步：接收用户请求
用户提供以下信息：
- 公司名称（如"海尔智家"、"安贤园中国"）
- 股票代码（如"600690"、"00922"）
- 报告类型（年报/中报）
- 年份（如2024、2025）

### 第2步：网络搜索
1. 构造搜索关键词："公司名称 年份 年报 PDF"或"公司名称 年份 中期报告 PDF"
2. 使用WebSearch工具搜索
3. 优先选择来源：
   - 公司官网投资者关系页面
   - 香港交易所披露易（港股）
   - 权威财经网站（雪球、腾讯财经等）

### 第3步：PDF下载
1. 使用curl命令下载PDF文件
2. 保存为临时文件（加"_temp"后缀）
3. 记录下载来源URL

### 第4步：文件验证
1. 使用pdfplumber提取第一页文本
2. 验证公司名称匹配（支持中文、英文、繁体变体）
3. 验证报告类型匹配（"年报"/"年度报告"/"Annual Report"/"全年業績"或"中报"/"中期报告"/"Interim Report"/"中期業績"）
4. 验证通过的文件继续处理，失败的文件记录原因

### 第5步：规范化存储
1. 创建目录：`company_analysis/{公司名称}_{股票代码}/`
2. 重命名文件：`{公司名称}_{年份}_{年报/中报}.pdf`
3. 移动文件到目标目录

### 第6步：生成日志
1. 创建下载清单：记录文件名、大小、来源、验证状态
2. 生成校验日志：包含验证详情和目录结构
3. 输出完成报告

## 快速开始

### 基本用法
当用户请求下载财报时，按以下步骤执行：

1. **确认需求**：明确公司名称、股票代码、报告类型、年份
2. **执行搜索**：使用WebSearch工具搜索PDF文件
3. **下载验证**：下载文件并使用verify_pdf.py验证
4. **存储整理**：按规范命名并存储到对应目录
5. **生成报告**：创建download_log.md记录下载详情

### 脚本使用
主脚本：[download_financial_reports.py](scripts/download_financial_reports.py)

```bash
# 基本用法
python3 download_financial_reports.py --company "海尔智家" --code "600690" --year 2024 --report-type "年报"

# 下载多个报告
python3 download_financial_reports.py --company "安贤园中国" --code "00922" --years 2024,2025 --report-types "年报,中报"
```

### 验证脚本
独立验证脚本：[verify_pdf.py](scripts/verify_pdf.py)

```bash
# 验证单个PDF文件
python3 verify_pdf.py --file "海尔智家_2024_年报.pdf" --company "海尔智家" --report-type "年报"

# 批量验证目录
python3 verify_pdf.py --dir "company_analysis/" --report
```

## 目录结构规范

```
company_analysis/
├── {公司名称}_{股票代码}/
│   ├── {公司名称}_{年份}_年报.pdf
│   ├── {公司名称}_{年份}_中报.pdf
│   └── download_verification.log（可选）
├── download_log.md（全局下载清单）
└── verification_report.md（全局验证报告）
```

## 注意事项

1. **文件验证**：必须验证第一页标题，确保为正式财报而非补充公告
2. **来源优先**：优先使用官方来源，避免中间处理版本
3. **命名规范**：严格遵循命名规范，便于后续自动化处理
4. **错误处理**：记录所有失败原因，便于问题排查
5. **网络限制**：注意网络请求频率，避免被网站屏蔽
