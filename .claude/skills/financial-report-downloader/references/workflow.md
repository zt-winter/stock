# 财务报告下载详细工作流程

## 工作流程图

```
用户请求 → 参数解析 → 网络搜索 → 来源评估 → PDF下载 → 文件验证 → 规范化存储 → 生成日志 → 完成报告
```

## 详细步骤

### 1. 参数解析与验证
- **输入参数**：
  - `company_name`：公司名称（中文或英文）
  - `stock_code`：股票代码（A股6位数字，港股5位数字）
  - `report_type`：报告类型（"年报"或"中报"）
  - `year`：年份（如2024、2025）
  - `output_dir`：输出目录（默认：`company_analysis/`）

- **验证规则**：
  - 股票代码格式验证：A股600000-699999，港股00001-09999
  - 年份验证：合理范围（如2000-当前年份+1）
  - 报告类型验证：必须是"年报"或"中报"

### 2. 网络搜索策略

#### 搜索关键词构造
- **基础关键词**：`{公司名称} {年份} {报告类型} PDF`
- **变体关键词**：
  - A股：`{公司简称} {年份}年年度报告`
  - 港股：`{公司名称} {年份} Annual Report`，`{公司名称} {年份} 年報`
  - 英文：`{英文公司名} {year} Annual Report PDF`

#### 搜索来源优先级
1. **官方来源**（最高优先级）：
   - 公司官网投资者关系页面
   - 交易所官方披露平台（披露易、巨潮资讯等）

2. **权威财经网站**（中等优先级）：
   - 雪球（xueqiu.com）
   - 腾讯财经（finance.qq.com）
   - 东方财富（eastmoney.com）

3. **通用搜索**（最低优先级）：
   - 百度搜索
   - Google搜索

#### 搜索技巧
- 添加"filetype:pdf"限定PDF文件
- 使用中英文双语搜索提高覆盖率
- 优先选择文件大小合理的链接（通常>100KB）

### 3. 来源评估与选择

#### 评估标准
- **URL可信度**：官方域名 > 权威财经域名 > 其他域名
- **文件信息**：优先选择直接PDF链接，避免中间页面
- **发布时间**：选择最新发布的版本
- **文件大小**：合理范围（年报通常500KB-10MB，中报200KB-5MB）

#### 常见官方域名模式
- A股公司：`*.cn`，`*.com.cn`
- 港股公司：`*.hk`，`*.com.hk`，国际域名
- 交易所：`hkexnews.hk`（披露易），`cninfo.com.cn`（巨潮）

### 4. PDF下载流程

#### 下载步骤
1. 使用`curl -L -o`命令下载，支持重定向
2. 保存为临时文件：`{公司名称}_{年份}_{报告类型}_temp.pdf`
3. 记录下载元数据：URL、时间、文件大小、HTTP状态码
4. 设置超时和重试机制（默认超时30秒，重试3次）

#### 错误处理
- **网络错误**：记录错误信息，尝试备用URL
- **HTTP错误**：记录状态码，跳过无效链接
- **文件错误**：检查文件完整性，删除损坏文件

### 5. 文件验证算法

#### 验证步骤
1. 使用pdf_helper兼容层（支持PyMuPDF/pypdf/pdfminer.six）打开PDF文件
2. 提取第一页文本（前1000字符）
3. 文本预处理：转换为小写，去除空格和标点
4. 关键词匹配验证

#### 关键词匹配规则

**公司名称匹配**：
- 基础名称：用户提供的公司名称
- 变体名称：繁体版、英文版、公司全称
- 匹配算法：部分匹配（包含关系），非精确匹配

**报告类型匹配**：
- 年报关键词：["年报", "年度报告", "Annual Report", "Annual", "年報", "全年業績", "全年业绩"]
- 中报关键词：["中期报告", "半年度报告", "Interim Report", "Interim", "中期", "半年度", "中期業績", "中期业绩"]

**排除规则**：
- 补充报告关键词：["补充", "补充公告", "补充报告", "Supplement", "Supplementary"]
- 业绩预告：["业绩预告", "盈利预告", "Profit Alert"]
- 其他文档：["演示稿", "Presentation", "简报", "Briefing"]

#### 验证结果
- **通过**：公司名称和报告类型同时匹配
- **失败**：任一条件不匹配或匹配排除关键词
- **不确定**：需要人工检查（记录原因）

### 6. 规范化存储

#### 目录结构
```
company_analysis/
├── {公司名称}_{股票代码}/
│   ├── {公司名称}_{年份}_年报.pdf
│   ├── {公司名称}_{年份}_中报.pdf
│   └── metadata.json（可选元数据）
├── download_log.md
└── verification_report.md
```

#### 命名规范
- **目录名**：`{公司名称}_{股票代码}`（中文名称，特殊字符替换为下划线）
- **文件名**：`{公司名称}_{年份}_{报告类型}.pdf`
- **日志文件**：`download_log.md`，`verification_report.md`

#### 文件操作
1. 创建目标目录（如果不存在）
2. 重命名临时文件为规范名称
3. 移动文件到目标目录
4. 更新目录索引

```markdown
- 失败数：Z

|---------|---------|---------|------|--------|----------|----------|----------|----------|
```

#### 校验报告（verification_report.md）
```markdown

## 验证统计
- 总验证文件数：X
- 验证通过：Y
- 验证失败：Z
- 验证率：YY%

## 详细验证记录
### 通过文件
1. 文件名：XXX，验证详情：...

### 失败文件

```

#### 错误日志
- 记录所有错误详细信息
- 包括时间戳、错误类型、错误消息、相关URL
- 便于问题排查和重试

### 8. 完成报告

#### 报告内容
1. **执行摘要**：总体统计和关键指标
2. **详细结果**：每个文件的处理状态
3. **目录结构**：生成的目录和文件列表
4. **问题汇总**：遇到的错误和警告
5. **建议操作**：需要人工干预的事项

#### 输出格式
- Markdown格式，便于阅读和分享
- 包含文件链接，便于直接访问
- 结构化数据，便于后续处理

## 高级功能

### 批量处理
- 支持公司列表批量下载
- 支持年份范围下载
- 支持多种报告类型组合

### 增量更新
- 检查目录中已存在的文件
- 跳过已成功下载的文件
- 只下载缺失或更新的报告

### 质量监控
- 文件完整性检查（PDF结构验证）
- 内容质量评估（页面数、文本比例）
- 版本比较（避免重复下载）

## 故障排除

### 常见问题
1. **网络连接失败**：检查代理设置，使用备用网络
2. **验证失败**：调整关键词匹配阈值，检查PDF编码
3. **命名冲突**：检查特殊字符处理，使用唯一标识符
4. **权限问题**：检查目录写入权限

### 调试模式
- 启用详细日志输出
- 保存中间文件供检查
- 逐步执行模式
