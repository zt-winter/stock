# 财务报告来源参考

## A股公司财报来源

### 官方来源

#### 1. 交易所指定信息披露平台
- **巨潮资讯网** (www.cninfo.com.cn)
  - 沪深交易所指定信息披露网站
  - 包含所有A股上市公司公告和报告
  - 搜索格式：`公司简称 + 年份 + 年年度报告`
  - 示例：海尔智家2024年年度报告

- **上海证券交易所** (www.sse.com.cn)
  - 上交所上市公司披露
  - 路径：披露 → 上市公司信息 → 定期报告

- **深圳证券交易所** (www.szse.cn)
  - 深交所上市公司披露
  - 路径：信息披露 → 上市公司信息 → 定期报告

#### 2. 公司官网投资者关系
- **常见域名模式**：
  - `*.cn`（中国域名）
  - `*.com.cn`（商业中国域名）
  - `ir.*.com`（投资者关系子域名）
  - `investor.*.com`（投资者子域名）

- **典型路径**：
  - `/investor-relations/`
  - `/ir/financial-reports/`
  - `/cn/investor/`
  - `/公告与报告/`

### 权威财经网站

#### 1. 雪球 (xueqiu.com)
- **搜索格式**：`股票代码 + 年份 + 年报`
- **URL模式**：`https://stockmc.xueqiu.com/{年份}/{股票代码}_*.pdf`
- **特点**：PDF文件通常为扫描版，质量较好
- **示例**：`https://stockmc.xueqiu.com/202508/600690_20250829_PKAX.pdf`

#### 2. 腾讯财经 (finance.qq.com)
- **搜索格式**：`公司名称 + 年份 + 年报 PDF`
- **URL模式**：`https://file.finance.qq.com/finance/hs/pdf/{年份}/{月}/{日}/*.PDF`
- **特点**：官方合作渠道，文件权威
- **示例**：`https://file.finance.qq.com/finance/hs/pdf/2025/03/28/1222926259.PDF`

#### 3. 东方财富 (eastmoney.com)
- **搜索格式**：`股票代码 + 年报`
- **路径**：数据中心 → 公告大全 → 定期报告
- **特点**：数据全面，更新及时

#### 4. 同花顺 (10jqka.com.cn)
- **搜索格式**：`公司简称 + 年度报告`
- **特点**：专业财经数据平台

### 搜索关键词策略

#### 基础关键词组合
1. `{公司名称} {年份} 年年度报告 PDF`
2. `{股票代码} {年份} 年报`
3. `{公司简称} {年份}年年度报告`
4. `{公司英文名} {year} Annual Report PDF`

#### 高级搜索技巧
- 添加`filetype:pdf`限定PDF文件
- 使用引号精确匹配：`"海尔智家 2024 年年度报告"`
- 排除词：`-演示稿 -简报 -预告`

## 通用搜索策略

### 搜索引擎选择

#### 1. 百度搜索 (baidu.com)
- **适用**：A股公司、中文内容
- **技巧**：
  - 使用`site:`限定域名：`site:cninfo.com.cn 海尔智家 年报`
  - 使用`filetype:pdf`限定文件类型
  - 添加`年份`提高准确性

#### 2. Google搜索
- **适用**：港股公司、英文内容、国际公司
- **技巧**：
  - 使用`site:hk`限定香港域名
  - 使用`intitle:`限定标题包含关键词
  - 使用`"Annual Report" "PDF"`精确匹配

#### 3. Bing搜索
- **适用**：备用搜索引擎
- **特点**：有时能找到其他引擎找不到的PDF

### 文件识别技巧

#### 1. URL特征识别
- **PDF文件特征**：
  - URL以`.pdf`结尾
  - 包含`/pdf/`路径
  - 包含`download`、`file`等关键词
  - 文件命名包含年份和报告类型

- **可疑URL特征**：
  - 包含`preview`、`view`（可能是预览页面）
  - 包含`html`、`aspx`（可能是中间页面）
  - 文件大小异常小（<50KB可能不是完整PDF）

#### 2. 文件大小判断
- **合理范围**：
  - 年度报告：500KB - 10MB
  - 中期报告：200KB - 5MB
  - 摘要版本：100KB - 2MB

- **异常情况**：
  - <50KB：可能是错误页面或占位符
  - >20MB：可能是高分辨率扫描版或包含大量图片

#### 3. 内容预览验证
- **优先选择**：
  - 直接PDF链接（无中间页面）
  - 官方域名发布的文件
  - 发布时间接近报告期的文件

- **避免选择**：
  - 第三方转发的文件
  - 水印明显的版本
  - 页面不完整的扫描版

## 常见问题解决方案

### 问题1：找不到PDF文件
**解决方案**：
1. 尝试不同关键词组合
2. 检查公司名称变体（全称、简称、英文名）
3. 尝试不同年份格式（2024、2024年、FY2024）
4. 使用公司股票代码替代公司名称搜索

### 问题2：找到的PDF不是正式报告
**解决方案**：
1. 验证第一页是否包含公司名称和报告类型
2. 检查文件大小是否在合理范围
3. 查看URL是否来自官方域名
4. 下载后使用验证脚本检查

### 问题3：网站需要登录或验证
**解决方案**：
1. 寻找其他不需要登录的来源
2. 尝试公开的PDF链接（可能绕过登录）
3. 使用公司官网的投资者关系页面（通常公开）
4. 使用交易所官方披露平台（完全公开）

### 问题4：下载链接失效
**解决方案**：
1. 尝试其他搜索结果的链接
2. 使用网站存档服务（如archive.org）
3. 联系公司投资者关系部门
4. 使用专业财经数据平台

### 问题5：PDF文件损坏或无法打开
**解决方案**：
1. 重新下载文件
2. 尝试其他来源的同一文件
3. 使用PDF修复工具
4. 转换为其他格式检查内容

## 最佳实践

### 搜索最佳实践
1. **多关键词组合**：使用公司名称、股票代码、报告类型、年份的不同组合
2. **多引擎搜索**：不要依赖单一搜索引擎
3. **来源验证**：优先选择官方和权威来源
4. **文件预览**：如果可能，先预览文件内容再下载

### 下载最佳实践
1. **临时存储**：先下载到临时位置，验证通过后再移动到目标目录
2. **重试机制**：对失败的下载自动重试
3. **超时设置**：合理设置下载超时时间
4. **进度跟踪**：记录下载进度和状态

### 验证最佳实践
1. **第一页验证**：必须验证第一页包含关键信息
2. **关键词扩展**：使用扩展关键词列表提高匹配率
3. **排除规则**：严格排除非目标文件类型
4. **质量检查**：检查文件完整性和可读性

### 存储最佳实践
1. **规范命名**：严格遵循命名规范
2. **目录结构**：按公司-股票代码组织目录
3. **元数据记录**：记录下载来源、时间、验证结果
4. **备份机制**：重要文件定期备份

## 特殊案例处理

### 公司名称变更
- 搜索历史名称和现用名称
- 检查公司更名公告
- 使用股票代码作为唯一标识

### 报告类型差异
- **年报变体**：年度报告、经审计年度报告、合并财务报表
- **中报变体**：中期报告、半年度报告、中期财务报表
- **补充报告**：业绩快报、盈利预告、补充公告（需排除）

### 语言版本处理
- **A股公司**：主要使用简体中文
- **港股公司**：中英文双语或单独版本
- **国际公司**：主要使用英文，可能有中文翻译版

### 财务年度差异
- **自然年度**：1月1日-12月31日（大多数A股公司）
- **财年**：4月1日-次年3月31日（部分港股公司）
- **其他财年**：根据公司业务特点设定
