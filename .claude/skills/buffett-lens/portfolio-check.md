# 持仓情绪问诊（portfolio-check）

**这个模式不产出任何买卖结论。** 它不估值、不算分位、不给目标价、不判断贵贱。

它只做三件事：

1. **命名当下的情绪**——把"我想做点什么"翻译成一个具体的心理状态；
2. **给出逐字原话**——从语料里检索 2–3 条直接相关的巴菲特原话，附 `chunk_id` 供复核；
3. **给出不行动清单**——列出本次不该做的事。

**为什么明写这条约束**：一旦允许它"顺便看一眼估值"，它就会变成择时工具，而择时正是这个模式要防的东西。股价大跌时的正确动作往往是什么都不做——一个总能给出动作的工具，会系统性地伤害使用者。

---

## 触发场景

- 持仓刚经历大跌，正在想要不要卖 / 要不要补
- 持仓刚大涨，正在想要不要止盈
- 看到别人赚钱，手里这只不动，正在烦躁
- 反复看盘，一天打开行情好几次

## 检索什么

按情绪类型选关键词，中英各查一轮（英文查 `letters`，中文查 `annual_meeting`）：

| 情绪 | 检索关键词（英 / 中） |
|---|---|
| 大跌想卖 | `Mr. Market` / `marketable securities` · `下跌` / `恐慌` / `耐心` |
| 大涨想止盈 | `selling` / `hold forever` · `卖出` / `长期持有` |
| 焦虑、想动手 | `temperament` / `inactivity` · `情绪` / `什么都不做` |
| 眼红别人 | `fear` / `greed` · `恐惧` / `贪婪` / `嫉妒` |

```bash
V=.venv/bin/python; S=.claude/skills/buffett-lens/scripts
$V $S/search_corpus.py search --query "Mr. Market" --source letters --limit 5
$V $S/search_corpus.py "恐慌" --limit 5
$V $S/search_corpus.py get --chunk-id <命中后取全文>
```

**检索不到就用 `search_corpus.py` 换关键词再查，不要凭记忆写"巴菲特说过"。** 语料覆盖：致股东信 1977–2024（英文原文）+ 股东大会问答 1994–2022（中译，缺 2017/2018）。查不到就写"本次语料未检索到相关表述"——这比编一句名言诚实得多。

## 输出模板

```markdown
# 持仓情绪问诊 · <日期>
> 本模式不产出买卖结论，只命名情绪、给出原话、列出不行动清单

## 一、当下是什么情绪
<用一句话命名：是恐惧？是贪婪？是焦虑？是眼红？>
<写清触发事件：股价从 X 跌到 Y，或从 X 涨到 Y>

## 二、巴菲特怎么说
> **原文**（<年>）: "<逐字引用>"
> 出处: `<chunk_id>` · 巴菲特致股东信 <年>

<同一格式 2–3 条，中英各取，来源分层署名>
> 中文引用署：巴菲特股东大会问答 <年>（CNBC 原文 · 中译：一朵喵）

## 三、不行动清单
- [ ] 今天不因为跌幅而卖
- [ ] 今天不因为涨幅而卖
- [ ] …（按具体情绪定制，写清"不做什么"，不写"应该做什么"）
```

## 纪律

1. **不出现"估值""分位""PE""目标价""贵/便宜"这些词。** 出现即违规——那是 `diagnostic-guide.md` 的领域，且需要完整的八项读数支撑。
2. **不给"下一步该做什么"**。只给不行动清单。
3. **原话必须逐字、必须带 `chunk_id`。** 报告里新增的引用先跑 `verify-quote`：
   ```bash
   $V $S/search_corpus.py verify-quote --year <年> --text "<引用文本>"   # exit 0 才算过
   ```
4. **不安慰、不打气。** 用户的情绪不需要被安抚，需要被命名。把"你现在的感受有名字，它在这份语料里出现过很多次"说清楚，比说"别担心"有用。

## 什么时候该转去完整问诊

问诊单（`diagnostic-guide.md`）处理的是**"这家公司值不值得持有"**，portfolio-check 处理的是**"我现在该不该动"**。区分很清楚：

- 情绪驱动、想立刻动手 → portfolio-check
- 想重新评估这家公司本身 → 完整问诊
- 两者都有 → 先做 portfolio-check，**等情绪平复后再做问诊**。带着情绪做的问诊，会不自觉地挑对自己有利的卡。
