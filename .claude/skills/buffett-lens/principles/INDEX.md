# 原则卡索引

15 张卡，6 组。**运行时绝不加载全部**——先判能力圈，再按生意的性质挑 4–6 张。

## 怎么用

1. **能力圈是前置关，不是并列项**。第一组两张卡没过，后面的数字再漂亮也不该看，到此为止。
2. 按「什么时候加载」一列挑卡。挑卡依据是**生意的性质**，不是"哪张看起来有利"——只挑对自己有利的卡等于没挑。
3. 每张卡加载后，用 `search_corpus.py` 检索 1–2 条逐字命中的原话，带 `chunk_id` 写进报告。**检索不到就明说检索不到，不得转述冒充引用**。
4. 每张卡以 PASS / QUESTION / REJECT 收尾，写清依据。

## 卡片格式

每张卡都是这个形状，`lint_citations.py` 会逐字校验引用：

```markdown
# 护城河持久性（Durable Moat）
**一句话**: ……
**判定标准**: 三条同时满足才算 PASS……（含数值阈值或 ROEJQ 这类真实字段名）
**巴菲特原话**:
> **原文**（2007）: "逐字引用"
> **出处**: `letters:2007:0020` · **来源**: letters · **检索关键词**: moat
**适用**: ……
**不适用**: ……
**反面案例**: ……
**关联**: pricing-power, roe-consistency
```

## 一、能力圈（前置关）

| 卡片 | 什么时候加载 | 与脚本读数的关系 |
|---|---|---|
| `circle-of-competence.md` | **每次都要**。先说清这家公司靠什么赚钱、列出 3 个竞争对手 | 脚本固定输出 `N/A — 需判定`，这一步脚本替不了 |
| `business-predictability.md` | 生意复杂、或所在行业变化快时 | 决定要不要相信 `ROEJQ` 的历史稳定性 |

## 二、护城河

| 卡片 | 什么时候加载 | 与脚本读数的关系 |
|---|---|---|
| `moat-durability.md` | **每次都要**。问"这优势三年后还在不在" | 【三】ROE一致性 + 【四】毛利率稳定性 + 【五】资本开支强度 |
| `pricing-power.md` | 有品牌、有提价历史的消费品 | 【四】毛利率稳定性（长期高且稳是最好的证据） |
| `roe-consistency.md` | 高 ROE 的公司——要区分"真高"与"周期顶/高杠杆撑的" | 【三】10年ROE一致性，含高杠杆剔除逻辑 |

## 三、管理层与资本配置

| 卡片 | 什么时候加载 | 与脚本读数的关系 |
|---|---|---|
| `owner-earnings.md` | **每次都要**。账面利润不等于股东能拿到的钱 | 【二】股东盈余 |
| `earnings-quality.md` | 利润增长快于现金流时必看 | 【六】盈利质量（OCF/净利润） |
| `capital-allocation.md` | 账上有大额现金、或有大额资本开支/并购 | 【五】资本开支强度 + 【八】一美元留存测试 |
| `management-integrity.md` | **每次都要**。品行问题一票否决 | 扣非与归母背离、口径频繁变更、回购价格 |
| `leverage-prudence.md` | 有息负债不低的公司；金融、地产必看 | 【七】杠杆（`ZCFZL` / `INTEREST_DEBT_RATIO`） |
| `retained-earnings-one-dollar.md` | 留存收益大、分红少的公司 | 【八】一美元留存测试 |

## 一票否决

【三】【四】【七】任一项 REJECT → **一票否决**，无论估值多低：

> 巴菲特不会因为便宜而买烂生意。

`buffett_analysis.py screen` 会直接打印这条结论。被否掉之后不要用"但是价格很便宜"去救它。
