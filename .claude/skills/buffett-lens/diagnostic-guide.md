# 巴菲特视角问诊方法论

本文档是 AI 执行巴菲特视角分析时的**解读框架和判断准则**。脚本负责检索原话与算数，AI 负责按此方法论解读并生成问诊单。

**这套东西不预测股价，也不给买卖建议。** 它做的是把"我觉得这家公司不错"拆成若干条**可以被推翻**的判定，每条判定要么挂着巴菲特的原话（可逐字复核），要么挂着脚本算出的数字（可重算）。剩下的部分必须被标成【推测】——标不出来源的话，就是话术。

## 一、三层架构与运行顺序

三层各自解决一个不同的问题，缺一层就退化成另一种东西：只有卡片 → 空谈原则；只有脚本 → 数字堆砌；只有语料 → 断章取义。

| 层 | 承担什么 | 载体 | 防的是 |
|---|---|---|---|
| 原则卡 | **准则**：判定标准与阈值 | `principles/*.md` | 想当然、"我觉得" |
| 量化筛查 | **数字**：可重算的读数 | `buffett_analysis.py` | 记忆里的财务印象 |
| 语料检索 | **原话**：逐字可溯的出处 | `search_corpus.py` | 编造"巴菲特说过" |

**运行顺序不能颠倒**：

```
⓪ 能力圈前置 ──── 说不清「靠什么赚钱」+ 3 个竞争对手 → 到此为止
        │
        ▼
① 挑卡 ──────── 按生意的性质从 principles/INDEX.md 挑 4-6 张
        │        （绝不加载全部 15 张）
        ▼
② 摸数据 ────── buffett_analysis.py data-check --code X
        │        先看清哪些数据缺，再决定哪几节能读
        │        字段级需求见 data-sources.md
        ▼
②' 分部证据 ─── buffett_analysis.py segment --code X（仅港股，有则跑）
        │        钱从哪来（⓪）+ 提价能否落地（①）的原始证据
        ▼
③ 量化筛查 ──── buffett_analysis.py screen --code X
        │        8 项读数【二】–【九】+ 汇总 + 一票否决
        ▼
④ 检索原话 ──── search_corpus.py，每张卡 1-2 条逐字命中，带 chunk_id
        │        检索不到就明说检索不到
        ▼
⑤ 拼问诊单 ──── 模板见 §五
                每条判定挂 chunk_id 或脚本行；挂不上的标【推测】
```

**⓪ 为什么必须在最前面**：一家你讲不清怎么赚钱的公司，后面的数字再漂亮也只是在给一个你没看懂的东西找理由。巴菲特把这条放在第一位，不是因为谦逊，是因为它是唯一能挡住大部分错误的关卡。脚本在这一步固定输出 `N/A — 需判定`——这不是缺陷，是设计。

**②' 分部证据怎么用**：`segment` 给出各分部的收入与**分部利润率**逐年走势（数据来自 `hk_segment_revenue`，由 `financial-report-pdf-extractor` 从年报分部附注抽出，合计校验与利润表对账两道闸门过了才入库）。这是唯一能直接回答「钱从哪来」和「提价能否落地」的读数，但它**只是证据，不是判定**：

- **收入增长本身不是定价权**。收入涨可能来自铺货、并表、降价换量。定价权要看到「收入增长的同时分部利润率没有塌」——利润率那一行才是正着。
- **口径不可跨**：`external_revenue`（对外销售）与 `segment_revenue`（含分部间销售）不是一回事。康师傅两者的差额是「其他來源之收入」（投资性房地产租金等），与利润表严丝合缝的是后者。拿两家的不同口径横向比，比出来的差异是口径差异，不是生意差异。
- **占比过小的分部不算利润率**：脚本对占当年总收入 <5% 的分部不列利润率——分母太小的话，总部分摊一进来比率就失去意义（康师傅「其他」分部收入仅占 0.8%，却摊着投资控股/租金/支援职能的开支）。
- **单年数据不算趋势**，至少看 5 年。库里没有该股数据时，先补年报再跑，**不要用记忆里的分部数字代替**。

## 二、原则卡使用规则

1. **按「适用」挑，不按「有利」挑**。只加载偏向自己结论的卡，等于没做检查。
2. **每张卡必须以 PASS / QUESTION / REJECT 收尾**，并写出依据。写完不判定的卡是读了个寂寞。
3. **引用必须逐字**。卡片里的原话都经过 `lint_citations.py` 三键校验（引文在全文里、年份对得上、chunk_id 确实包含它）。你自己在报告里添的引用，同样要过 `search_corpus.py verify-quote`。
4. **署名要分层，不把译文说成原话**：
   - `letters` → `巴菲特致股东信 <年>`（英文原文，一手）
   - `annual_meeting` → `巴菲特股东大会问答 <年>（CNBC 原文 · 中译：一朵喵）`，并附 `buffett.cnbc.com`
   把中译标成"巴菲特原话"是不诚实的。语料本身也要求注明 CNBC 来源。
5. **检索 0 结果不等于"巴菲特没说过"**。当前语料是：致股东信 1977–2024（英文原文）+ 股东大会问答 1994–2022（中译，**缺 2017、2018**，2019/2020 残缺）。查不到就换关键词或换语言再查；仍然查不到，就在报告里写"本次语料未检索到"，不要转述凑数。

## 三、数字的来源分层与准入

**报告里的每一个数字都必须说得出它是从哪一级来的。** 分级不是为了好看，是因为**不同级别的数字能承担的判定权重不同**——把 C 类当 A 类用，是这套工具最容易犯、也最难被自己发现的错误。

| 级别 | 来源 | 怎么复核 | 能承担什么 |
|---|---|---|---|
| **A · 可重算** | `financial_data.db`（三表 / `hk_segment_revenue` / `stock_valuation_history` / `dividend_annual_yield` / `hk_yield_cache`） | 重跑 `buffett_analysis.py`，数字必须一致 | **可作判定依据** |
| **B · 年报原文** | 年报/中报 PDF 正文，**必须给页码**（`[年报<年> p<n>]`） | 翻到该页逐字核对 | **可作判定依据**；但单条 B 类无对账，不足以独撑一条判定 |
| **C · 外部来源** | 财经媒体、市场研究、券商研报、搜索摘要 | **不可复核** | **只许进「我的推测」一节，不得出现在第一至四节的任何依据栏** |
| **D · 语料** | `buffett_corpus.db`，带 `chunk_id` | `search_corpus.py get --chunk-id` + 三键校验 | **可作判定依据**（引用） |

**三条硬约束**

1. **C 类不得作为判定依据。** 这是最容易破的一条：C 类数字往往**正是你想要的那个数**（市占率、门店数、竞品对比），而且看起来比年报里的更精确、更整齐。**但它穿过了零道闸门。** 需要 C 类才能成立的判定，就是**证据不足的判定**——降级为 QUESTION，或整条移进「我的推测」。
2. **每个数字都要标级别**（A 无标记 / B 带页码 / D 带 `chunk_id`），或写明它是脚本的哪一行输出。**不标级的数字一律按 C 类处理**——宁可标不出来源，也不要让它看起来像是年报来的。
3. **C 类必须写出它的来源类别，不能写成"年报显示"。** 把媒体报道标成"年报披露"是不诚实的，与 §二.4 把中译标成"巴菲特原话"是同一类错误。

**为什么单列一节**：上面两层（原则卡给准则、脚本给数字）都有闸门，语料层有 `lint_citations.py` 管着。**唯独"经营数据"这一格没有闸门**——经销商数、市占率、产能、门店数都不在三张表里，只能从年报 MD&A 散文或外部来源拿。既然没有闸门，就必须有限制：**它只许描述生意，不许单独支撑判定。**

**拿到 B 类经营数据之后，还有三条要当心**（这类数据即使出自年报，性质也与财报不同）：

- **公司自述 ≠ 经审计**。财报有审计、有准则约束、口径变更要披露；经营数据是公司自己数的，**"经销商"的定义改了你不会收到通知**。用之前先看这个口径在过去几年有没有突然跳变——例如康师傅 `[年报<各年> p8]` 的經銷商从 2019 年 36,186 升到 2021 年 80,726（两年 2.23 倍），恰逢 2021 年 3 月 PepsiCo 战略联盟落地，计数口径很可能并进了他方网络。**跨过这种断点的同比是假的。**
- **页内没有"合计"就没有自校验**。分部数据能对账（Σ分部+冲销==总计、与利润表勾稽），销售网络表不能。此时**唯一的闸门是跨年报重叠披露**——同一财年被相邻年报各披露一次（康师傅 p8 是五年滚动窗口，2021–2023 各被披露三次），**逐字一致才算数**。
- **平滑性只报警、不拦截**。跨年无十倍跳变能说明"不像抄错"，**证明不了"对"**。别把探测器当闸门用。

## 四、量化筛查读数规则

### 4.1 NA 不是 PASS

样本不足时脚本输出 `NA`：

| 指标 | 最低样本 |
|---|---|
| ROE 一致性、毛利率稳定性、盈利质量 | 7 年 |
| 一美元留存测试 | 5 年 |

**样本不足一律记 NA，不记 PASS。** 报告里的"通过初筛"要求 PASS ≥6 且 REJECT = 0；一堆 NA 凑出来的项数不算通过。

### 4.2 一票否决

【三】护城河（ROE 一致性、毛利率稳定性）、【六】盈利质量、【七】杠杆——**任一项 REJECT 即一票否决**：

> 巴菲特不会因为便宜而买烂生意。

被否掉之后，**不要用"但是价格很便宜"去救它**。REJECT 指向的是生意的性质，价格下跌不改变生意的性质。

### 4.3 必须显式读出的修正项

脚本会打印这些提示，它们**改变了数字的读法**，不能跳过：

- **周期股 PE 分位语义反转**。对 `601600`、`601919` 这类强周期股，PE 低往往是利润在周期顶部的爆发（危险），PE 高反而是底部。此时**改以 PB 为主信号**，并对照 `security-analysis` 技能的 `cyclical-analysis-guide.md` §一。不校正的话，会把周期顶读成便宜。
- **股息口径**。一美元留存测试的股息取自 `ASSIGN_DIVIDEND_PORFIT`（"分配股利、利润或偿付利息支付的现金"）——这个科目**把利息支付也算作股息**，于是股息被高估、留存被低估，测试因此**偏保守**。偏保守的方向是安全的，但读数时要记住。
- **高杠杆虚高的 ROE**。某年 `ZCFZL > 60%` 时该年 ROE 会被剔出最低值判定；剔除后样本跌破 7 年则记 NA，而不是 PASS。
- **毛利率的绝对水平是行业相对的**。消费品 40% 与重资产 20% 不可直接比较。本判定只看**稳定性与绝对水平的组合**，不含行业基准——所以它不能单独用来否决一家重资产公司，要和【三】ROE 一起看。
- **capex/折旧摊销的比值**。≈1 是维持性开支，>2 是扩张性投入。扩张性投入本身不是坏事，但要额外问一句：这些产能投出去能赚回原来的回报率吗。
- **市值推算存在分歧**时（`pe_ttm × 净利` 与 `pb × 净资产` 两法背离 >20%），脚本会告警，结论可靠性下降。

### 4.4 数字回答不了的那一半

脚本最后会打印一句话，值得抄进报告：

> 数字只回答「生意好不好、价格贵不贵」，回答不了「你是否真的懂它」。

八项读数全 PASS，只说明这是一家好公司、价格不贵，**不说明它在你能力圈内，也不说明你该买**。

**填写纪律**：

1. 每条判定必须挂 `chunk_id`、脚本输出行、或 B 类页码（`[年报<年> p<n>]`）。**挂不上的一律进第五节标【推测】**，不许混在第一到四节里冒充结论。
2. **C 类数字（媒体/研报/搜索摘要）不得出现在第一至四节的依据栏**，只许进第五节，且必须带【外部·未经年报核实】标记。详见 §三。
3. 引用块里的 `chunk_id` 必须是真实检索到的；报告里新增的引用要先跑 `verify-quote`。
4. 涉及的每一张卡都要写判定，不许因为拿不准就省略——拿不准就写 QUESTION 并说明缺什么。
5. **第七节"数据来源"必填**。它逼你在收尾时回头看一眼：这份单子里有没有哪个数字说不清自己是哪来的。

## 六、常见陷阱

| 陷阱 | 表现 | 怎么破 |
|---|---|---|
| 用便宜救烂生意 | "虽然 ROE 一路下滑，但 PE 才 8 倍" | 一票否决不可讨价还价。价格不改变生意性质 |
| 周期顶读成便宜 | 强周期股 PE 分位极低就判 PASS | §4.3 第一条，改看 PB |
| 把 NA 读成 PASS | 数据缺失，于是"没发现问题" | NA 是"不知道"，不是"没问题" |
| **外部数字混进判定依据** | 媒体给的市占率/门店数被写成"年报显示"，还挂进了护城河或定价权的依据栏 | §三：C 类只许进「我的推测」；**需要它才能成立的判定，降为 QUESTION** |
| **把公司自述当事实** | 拿年报里"經銷商净减"直接推出"渠道在萎缩" | §三末：经营数据无审计、无对账；先看口径有没有跳变，再看是不是只是结构切换（经销商减、直营增是另一种故事） |
| **跨口径横比** | 拿 A 家"单分部利润率"比 B 家"整分部利润率"，读出"赚钱能力差 6 倍" | 分母范围不同就不可比；**不可比就写不可比**，不要给一个漂亮数字 |
| 转述冒充引用 | 把大意写成引号里的"原话" | 逐字校验；做不到就用间接引语并注明是转述 |
| 中译标成原话 | 引用中文却署"巴菲特致股东信" | §二.4 的分层署名 |
| 只挑有利的卡 | 高杠杆公司跳过杠杆卡 | §二.1，按"适用"挑 |
| 用历史涨幅证明未来 | "过去十年涨了 7 倍，说明管理层优秀" | 一美元留存测试测的是留存收益的转化效率，不是股价 |
| 长期持有当借口 | 用"永久持有"解释任何不卖 | `sell-discipline` 卡：不卖也要有理由，理由不该只是"还没涨够" |

---

**最后**：这套工具的价值不在于给出答案，而在于**迫使每个结论亮出出处**。一份问诊单里如果有 5 条【推测】和 2 条挂得住出处的判定，它依然是诚实的；反过来，一份全是斩钉截铁的结论、却找不到一个 `chunk_id` 的报告，无论写得多漂亮都是幻觉。
