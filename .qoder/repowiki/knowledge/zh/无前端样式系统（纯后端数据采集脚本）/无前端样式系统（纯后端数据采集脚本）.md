该仓库是一个纯 Python 数据采集工具集，用于抓取 A 股/港股财报与 ETF 申赎清单数据并落库 SQLite。经全仓检索，未发现任何 CSS、SCSS、HTML 模板、前端框架或 UI 相关代码：
- 无 `*.css` / `*.scss` / `*.less` / `*.styl` 文件
- 无 `tailwind.config.*`、主题文件或设计令牌
- 无 Flask/Django/FastAPI/Streamlit/Gradio 等 Web 框架引用
- 所有匹配仅涉及 HTTP URL 字符串（作为数据源地址），而非前端资源加载

因此本仓库不存在“前端样式”这一横切关注点，属于 backend-only 脚本集合。
